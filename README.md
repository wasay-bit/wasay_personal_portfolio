# Wasay Omair — Portfolio

A personal portfolio site with a security-console look: an access-badge hero, experience,
case-study project cards, skills, involvement, recommendations and a small terminal.

## Files

- `client.js` entry point. It hands over to `site.js`.
- `site.js` page assembly, navigation, light and dark theme, motion.
- `data.js` the site's text: profile, experience, skills, certifications, involvement and more.
- `projects.js` project data, filters and case-study cards. `diagrams.js` draws the flow diagrams.
- `sections.js` section builders for the page.
- `hero.js` the top of the page and the résumé buttons. `kit.js` shared helpers.
- `shell.js` the terminal.
- `background.js` the decorative network background. `logos.js` company and school logos.
- `styles.js` and `styles2.js` the styles. `dom.js` small helpers for building elements.
- `server.js` stores the photos and the résumé.
